\section{Sharp bounds from confusion counts}\label{sec:identification}
A confusion matrix can be exactly correct for the target items and still fail
to determine a downstream estimate. This is an information problem before it
is a sampling problem. Fix the predictions $q$ and the item weights $w$
in equation~\eqref{eq:estimand}. We now ask what a validation
summary establishes about the fixed target $\theta=w^{\mathsf T}y$, without
specifying a stochastic model for how the classifier's mistakes were generated.

Let $P=\{j:q_j=1\}$ and $N=\{j:q_j=0\}$. Suppose the entire target-population
confusion matrix is known: $f$ predictions in $P$ are false positives and $g$
predictions in $N$ are false negatives. This grants more information than ordinary
held-out validation, whose error rates require a transport assumption.
For a finite collection $B$ of weights, let $S_-(B,m)$ and $S_+(B,m)$ denote
the sums of its $m$ smallest and largest elements, with a zero sum when $m=0$.

\begin{proposition}[Sharp bounds from confusion counts]\label{prop:bounds}
Across binary label vectors compatible with $q,f,g$, the smallest and largest
possible errors $\Delta=\widehat\theta-\theta$ are
\begin{align}
 L&=S_-(w_P,f)-S_+(w_N,g),\notag\\
 U&=S_+(w_P,f)-S_-(w_N,g).
\end{align}
Consequently $[\widehat\theta-U,\widehat\theta-L]$ is the smallest interval
containing every compatible value of $\theta$. Both endpoints are attainable.
\end{proposition}
\begin{proof}
Only false positives and false negatives contribute:
$\Delta=\sum_{j\in\mathrm{FP}}w_j-\sum_{j\in\mathrm{FN}}w_j$.
Select $f$ indices from $P$ and $g$ from $N$. The two selections have disjoint
supports and no other restrictions. Selecting the smallest positive-stratum
weights and largest negative-stratum weights minimizes the error; reversing
these selections maximizes it. Assign the selected indices the corresponding
true labels to attain each endpoint.
\end{proof}
The compatible values form a finite set, so the interval is its convex hull;
not every interior value need be attainable. A reported sign is established by
these counts only if the bounding interval excludes zero. The calculation
requires sorting, rather than a general integer-programming solver.

For example, take $q=(1,1,0,0)$, $w=(1,-1,1,-1)$, and $f=g=1$.
The same confusion matrix permits errors of $-2$, $0$, and $2$.
Prevalence, accuracy, FPR, and FNR are identical across those assignments.
Adding correctly classified items with zero weight makes accuracy arbitrarily
close to one without resolving the target. In the browsing application, these
can be domains that affect individual exposure but cancel from a group contrast.

\begin{proposition}[When counts suffice]\label{prop:sufficient}
In a stratum of $M$ items sharing the same predicted label, with exactly
$m$ errors, the error sum is
point identified if and only if $m\in\{0,M\}$ or all its contrast weights are
equal. Its identification width obeys
\begin{equation}\label{eq:dispersion}
 S_+(w,m)-S_-(w,m)
 \leq \min(m,M-m)\{\max_jw_j-\min_jw_j\}.
\end{equation}
Widths add across strata. For several comparisons, counts determine every
comparison if and only if their vector of item weights is constant within
each stratum with an interior error count.
\end{proposition}
\begin{proof}
Constant weights, no errors, and all errors each determine the sum. If
$0<m<M$ and two weights differ, choose an error set containing one of those
indices but not the other. Exchanging them changes the sum, proving necessity.
The difference between two sums of $m$ terms is at most $m$ times the range.
Taking complements gives the corresponding bound with $M-m$ terms. The
vector statement applies the exchange argument to each coordinate.
\end{proof}
For a stratum mixing predicted labels, the corresponding criterion applies to
the signed contributions $(2q_j-1)w_j$, not to $w_j$ alone.
The result specifies what a finer validation table must preserve. Stratifying
by predicted label alone is sufficient only when the contrast attaches equal
weights within each partially erroneous stratum. Partitioning items by
similar contrast weights can reduce ambiguity; bins chosen for one comparison
need not work for another. In browsing, error rates conditional on user
demographics are not automatically available: the same domain can enter many
groups.

\section{Audit count bounds and linear corrections}\label{app:validation}
An existing probability sample of verified target items can recover information
that a confusion matrix discards; it need not have been allocated optimally.
The construction uses established finite-population counting and audit ideas
\citep{stark2008audits,shekhar2023audits}. Partition the target items using
information known before labels are audited, then draw a fixed-size random
sample without replacement within each stratum. Exact hypergeometric
inversion gives a confidence interval $[\ell_h,u_h]$ for the number of
incorrect predictions in stratum $h$; allocate error probabilities across
strata so their sum is at most $\delta$.

Let $O$ contain the audited items and $\mathcal Y_A$ the binary label vectors
that match their verified labels and whose error counts in each stratum lie
in $[\ell_h,u_h]$. Its construction and the sorting formula for its extremes
are in Appendix~\ref{app:audit}.
\begin{proposition}[A simultaneous count certificate]\label{prop:audit}
For any fixed item weights $w$, the interval
$[\min_{z\in\mathcal Y_A}w^{\mathsf T}z,
  \max_{z\in\mathcal Y_A}w^{\mathsf T}z]$
covers the fixed target $w^{\mathsf T}y$ with probability at least
$1-\delta$ over the audit design. The same event covers every linear contrast
of this one label vector. Its endpoints are sharp given the audited labels
and the count intervals.
\end{proposition}
The certificate is simultaneous because the count event constrains the same
label vector for every $w$. It can nevertheless be wide: it retains error
counts but discards the weights attached to unaudited error locations.
The example and full audit comparison in Appendix~\ref{app:audit} show this
loss. Those simulations evaluate a design chosen for one coefficient; they
do not establish efficient simultaneous auditing for other contrasts.

For one declared contrast, a stratified difference estimator instead keeps
the audited item identities and their weighted residuals:
\begin{equation}\label{eq:directaudit}
 \widetilde\theta=\widehat\theta+
 \sum_h\frac{M_h}{n_h}\sum_{j\in O_h}w_j(y_j-q_j).
\end{equation}
With fixed predictions and verified labels, this estimator is design
unbiased. A normal interval needs a separate approximation. The conservative
finite-sample Hoeffding interval in the appendix is wide in this application;
the paper does not establish an efficient finite-sample interval or an
optimal audit allocation. The distinction here is between preserving the
locations of audited errors and reducing them to counts.

The same collected labels can correct several estimates jointly. Let $W$
contain their item-weight vectors, let $R_j$ indicate that item $j$ was
verified, and let $\pi_j>0$ be its known inclusion probability. Set
$g_j=(y_j-q_j)W_{j\cdot}^{\mathsf T}$. With predictions frozen before the
validation sample was selected,
\begin{equation}\label{eq:jointdirectaudit}
 \widetilde{\boldsymbol\theta}
 =W^{\mathsf T}q+\sum_j\frac{R_j}{\pi_j}g_j,
 \qquad \E_R[\widetilde{\boldsymbol\theta}]=W^{\mathsf T}y.
\end{equation}
The reusable item, not each downstream record, is the sampling unit. If
$\pi_{j\ell}=\Pr_R(R_j=R_\ell=1)$ and $\pi_{jj}=\pi_j$, the exact joint
design covariance is
\begin{equation}\label{eq:jointauditvariance}
 \Cov_R(\widetilde{\boldsymbol\theta})
 =\sum_{j,\ell}
   \frac{\pi_{j\ell}-\pi_j\pi_\ell}{\pi_j\pi_\ell}
   g_jg_\ell^{\mathsf T}.
\end{equation}
If every relevant $\pi_{j\ell}>0$, replacing each summand by
$R_jR_\ell/\pi_{j\ell}$ times that summand gives an unbiased covariance
estimator. For independent Bernoulli item selection, only the diagonal terms
remain, giving
$\sum_j(1-\pi_j)(y_j-q_j)^2
W_{j\cdot}^{\mathsf T}W_{j\cdot}/\pi_j$.
The off-diagonal entries of this covariance describe how a single verified
item corrects several reported estimates together. Highly influential items
with small $\pi_j$ can leave a valid estimator with a very unstable variance
estimate and a poor normal approximation.

If validation items were chosen purposively and their inclusion probabilities
are unknown, these design claims do not apply. One can instead state a model
for how validation errors transfer to the target items, or report bounds under
explicit restrictions. A confusion matrix from a convenience set does not
identify either the target-item correction or its standard error. The
ordinary regression standard error conditional on frozen predictions answers
a different question; it does not include the error from unverified labels.
If the same selected labels were used to fit the predictions, the frozen-proxy
design argument also needs modification; cross-fitting or joint analysis of
training and validation would require its own justification.

\section{Score calibration and conditional means}\label{app:calibration}
The bounds from exact target-item confusion counts and the probability audit
above condition on fixed predictions and labels. Neither requires calibrated
classifier scores. The audit needs a known probability-sampling design for
target items and verified labels for the sampled items. If the
error counts come instead from a separate validation collection, applying them
to the target items requires a transport assumption, whether or not that
collection's scores are calibrated.

A score-based plug-in uses a different source of information. Let
$p_j\in[0,1]$ be a score intended to represent the probability that target
item $j$ has label one, and put $\theta_p=w^{\mathsf T}p$. To interpret this as
a conditional mean, introduce a model in which the labels are random given
information $\mathcal I$ containing the scores and the target weights. Write
$\mu_j=\E[y_j\mid\mathcal I]$. Then
\begin{equation}\label{eq:scorebias}
 \E[\theta_p-\theta\mid\mathcal I]
 =w^{\mathsf T}(p-\mu).
\end{equation}
The plug-in equals $\E[\theta\mid\mathcal I]$ if and only if this weighted
error is zero. A sufficient condition is $p_j=\Pr(y_j=1\mid\mathcal I)$ for
each target item. For a particular target, offsetting score errors can also
make the weighted sum zero without item-level conditional calibration.

Ordinary calibration, $\Pr(y=1\mid p=s)=s$ across items, is weaker. For
example, let half the items have label one and weight one, and the other half
have label zero and weight zero. Give every item score $1/2$. The scores are
empirically calibrated in the unweighted item collection, but $\theta_p$ is only
half of the realized target. Conditioning on features that distinguish the
two weight groups, or directly checking the weighted residual, exposes the
failure. Calibration assessed on a separate collection also has to transfer
to the target items and their label definition.

For a browsing visit share, $w_j=v_j/\sum_\ell v_\ell$ gives
$\theta_p=\sum_jv_jp_j/\sum_jv_j$. Conditional probabilities for the specified
content label would make this the model's expected visit share. A group
contrast or regression coefficient has different, possibly signed weights;
its required weighted score condition changes accordingly.

Even valid target-item conditional probabilities identify a conditional
expectation, not the realized finite-item target. Under the conditional-label
model, uncertainty around that expectation depends on the joint distribution:
\begin{equation}\label{eq:scorevariance}
 \Var(\theta\mid\mathcal I)
 =w^{\mathsf T}\Cov(y\mid\mathcal I)w.
\end{equation}
Item-level calibration supplies neither the off-diagonal covariances nor, by
itself, a coverage guarantee for an interval about the realized target.
Estimating the scores introduces further uncertainty. These model-based claims
are distinct from the fixed-label, design-based coverage of the audit.
